# Synthetic Milestone Contract Example

Synthetic only. Parent/child membership is derived without duplicate light ownership. Narrative lock/decision, topology device tag/room association and provisional annotation identity demonstrate the contracts; there is no project PDF or proven PDF readback.

Run model_intake on lighting-model.json, validate_topology on topology.json paired with the lighting model, and milestone_markup export through 3 for printable review schedules. The example does not establish sensor coverage, electrical equipment allocation or construction readiness.
