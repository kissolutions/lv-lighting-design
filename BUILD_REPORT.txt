Updater execution
-----------------
The pushed overlay was detected on the source commit. The M4 updater was executed locally against exact snapshots of the files it modifies.

Two defects were found and corrected before packaging:
1. Schema definition lookup used $defs.light_object, while the live v0.5 schema uses $defs.light.
2. The exporter patch was not actually idempotent; a second updater run duplicated source_power_type / lv_input_power_type fields. The updater now guards those edits and a second run leaves the files unchanged.
